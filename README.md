# Dental Pharma Project Performance Dashboard

## Project Overview

This project uses Microsoft Power BI to analyse project performance across different countries and regions for Dental Pharma.

The dashboard was designed to help users monitor project costs, duration, delivery performance and financial trends while allowing them to filter the analysis by country or region.

## Business Objectives

The main objectives of the dashboard were to:

* Identify projects running across different countries
* Compare planned and actual project costs
* Identify countries where projects are over budget
* Compare planned and actual project duration
* Identify countries where projects exceed their planned duration
* Identify countries that are under-delivering against project targets
* Monitor financial performance over time
* Analyse the distribution of project durations

## Key Metrics

The dashboard focuses on several project performance measures, including:

* Planned Cost
* Actual Cost
* Percentage Over Budget
* Planned Duration
* Actual Duration
* Percentage Over Duration
* Project Delivery Performance

## Dashboard Features

### Project Overview

A project-level view was created to show which projects are running or have previously run in different countries.

Users can filter the dashboard by country or region to investigate specific projects.

### Countries Over Budget

The dashboard identifies countries where actual project costs exceed planned costs.

An adjustable threshold allows users to investigate projects based on the percentage by which they exceed their planned budget.

### Countries Over Duration

Project duration performance is analysed by comparing actual duration against planned duration.

This allows users to identify countries where projects are taking longer than expected.

### Countries Under-Delivering

The dashboard provides analysis of countries where actual project delivery is below the expected target.

This helps highlight areas where project performance may require further investigation.

### Financial Performance Over Time

A time-series visualisation is used to analyse how project financial performance changes over time.

Users can filter the analysis by country or region to investigate specific areas.

### Project Duration Analysis

A histogram is used to analyse the distribution and frequency of project durations.

This provides additional insight into how long projects typically take to complete.
